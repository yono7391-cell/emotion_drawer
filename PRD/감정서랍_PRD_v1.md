## 1. 개요

### 1-1. 한 문장 정의

내 마음을 어떻게 표현해야 할지 막막한 사람이 **상황 → 생각 → 감정 → 욕구** 4단계 질문을 따라 감정을 기록하고, 쌓인 기록을 돌아보며 반복되는 자신의 마음을 발견하도록 돕는 웹앱.

### 1-2. 배경

- 기존 감정 기록 앱은 꾸미기·캐릭터(몽글하루, 오늘도 감정일기) 또는 숫자 통계(Daylio)가 중심이라, 감정이 생긴 **맥락**까지 정리하기 어렵다.
- 타깃 사용자는 '감정을 알아차리라는데 어떻게 하는지 모르겠다'는 막막함과 '매일 써야 한다'는 부담을 느낀다.
- 감정서랍은 진단·치료가 아닌 **기록과 회고를 돕는 도구**다.

### 1-3. 대상 사용자

| 항목 | 내용 |
|---|---|
| 핵심 타깃 | 20대 후반~30대 초중반 직장인, 상담을 고민 중이지만 위기 상황은 아님 |
| 주 유입 경로 | 인스타그램(모바일), 검색·AEO, 앱 추천 콘텐츠 |
| 주 사용 기기 | 모바일 브라우저 **[가정]**: 인스타그램 유입이 주력이므로 모바일 우선 |

### 1-4. 이번 버전 범위

| 포함 | 범위 밖 (이번 버전에서 만들지 않음) |
|---|---|
| 랜딩페이지 (히어로, 4단계 소개, 체험, 요금, FAQ, 위기 안내) | 실제 결제·구독 처리 (요금표는 보여주기만 함) |
| 가입 없이 해보는 4단계 체험 | 이메일·웹 푸시 실제 발송 (수신 동의 저장까지만) |
| 회원가입·로그인·로그아웃 | 소셜 로그인, 비밀번호 찾기 |
| 감정 기록 작성·조회·수정·삭제 | AI 요약·AI 답장 |
| 내 서랍 (기록 목록, 감정 필터) | 테마·꾸미기·스티커 |
| 회고 (감정 횟수, 함께 기록된 감정·욕구) | 관리자 화면, CRM 대시보드 |
| Plus 1개월 체험 상태와 기능 잠금 | 네이티브 앱, 오프라인 동기화 |
| 내 기록 내려받기, 계정·기록 전체 삭제 | 기록 공유·공개 기능 (만들지 않는 것이 원칙) |
| GA4 이벤트 측정 | 위기 단어 자동 감지 |

## 2. 목표

### 2-1. 제품 목표

1. 처음 온 사람이 **가입하지 않고도 1분 안에** 4단계 기록을 끝까지 경험한다.
2. 체험한 기록을 버리지 않고 **가입과 동시에 첫 기록으로 저장**할 수 있다.
3. 기록이 3개 이상 쌓이면 **회고 화면에서 반복되는 감정과 바람을 볼 수 있다**.
4. 사용자가 자신의 기록을 **언제든 내려받고 완전히 삭제**할 수 있어 안심하고 쓴다.

### 2-2. 측정 지표 (모두 기획서의 [가설])

| 지표 | 산식 | 목표 | 데이터 출처 |
|---|---|---|---|
| 체험 완료율 | 체험 4단계 완료 ÷ 체험 시작 | 기준값 수집 **[가정]** | GA4 |
| 가입 전환율 | 가입 ÷ 랜딩 방문 | 기준값 수집 **[가정]** | GA4 |
| 첫 기록 완료율 | 가입 후 7일 내 첫 기록 사용자 ÷ 가입 사용자 | 30% | DB (`users`, `entries`) |
| 회고 진입률 | 기록 3개 이상 사용자 중 회고 화면 방문 사용자 비율 | 기준값 수집 **[가정]** | GA4 + DB |

> CRM 관련 지표(재기록률 20%, 재방문율 25%)는 메시지 발송이 범위 밖이므로 이번 버전에서 측정하지 않는다.

### 2-3. 하지 않을 것 (원칙)

- 연속 기록, 출석 보상, 매일 알림처럼 기록을 압박하는 장치
- 감정을 '좋음/나쁨', '긍정/부정'으로 평가하는 표현이나 색 구분
- "당신은 ○○한 사람이에요"처럼 사람을 단정하는 회고 문장
- 진단·치료 효과를 약속하는 문구
- 가짜 사용자 후기, 사용자 수 같은 근거 없는 수치

## 3. 사용자 시나리오

### 시나리오 A — 처음 방문해서 체험하고 가입하기

1. 지수(29세, 직장인)는 인스타그램 광고를 보고 휴대폰으로 랜딩페이지에 들어온다.
2. 히어로의 **[감정 하나 골라보기]**를 누르고 '서운함'을 고른다.
3. 상황 → 생각 → 감정 → 욕구 질문에 짧게 답한다. 생각 단계는 건너뛴다.
4. 마무리 화면에서 방금 쓴 기록 요약을 보고 **[서랍에 보관하기]**를 누른다.
5. 가입 화면으로 이동해 이메일과 비밀번호로 가입한다.
6. 가입이 끝나면 체험 기록이 첫 기록으로 저장되고 '내 서랍' 화면으로 이동한다. Plus 1개월 체험이 자동으로 시작된다.

### 시나리오 B — 다시 와서 기록하고 돌아보기

1. 지수는 일주일 뒤 회의에서 속상한 일이 있어 로그인한다.
2. **[새 마음 담기]**로 기록을 남긴다.
3. 기록이 3개가 되자 내 서랍 상단에 '회고' 안내가 보인다.
4. 회고 화면에서 최근 30일 동안 '서운함'을 3번 기록했고, 그때마다 '인정'을 바랐다는 정리를 본다.
5. 지난 기록을 눌러 다시 읽고 메모를 덧붙인다(수정).

### 시나리오 C — 내 기록을 정리하고 떠나기

1. 지수는 설정에서 이메일 알림 수신을 끈다.
2. **[내 기록 내려받기]**로 전체 기록을 CSV로 받는다.
3. **[계정 삭제]**를 누르고 확인 문구를 입력하면 계정과 모든 기록이 즉시 삭제된다.

### 시나리오 D — 체험 기간이 끝난 사용자

1. 가입 후 30일이 지나면 Plus 체험이 끝난다.
2. 기록 작성·조회·기본 회고는 그대로 쓸 수 있다.
3. Plus 기능(상세 회고, 키워드 검색)은 잠김 표시와 함께 "Plus는 출시를 준비하고 있어요." 안내가 나온다. 자동 결제는 없다.

| Q6 | 감정 기록 앱과 종이 다이어리는 어떤 차이가 있나요? | 종이 다이어리는 형식 없이 자유롭게 쓰기 좋고, 감정서랍은 단계별 질문으로 시작을 돕고 쌓인 기록에서 자주 나타난 감정과 바람을 모아 보여줍니다. 어느 쪽이 더 낫다기보다 나에게 맞는 방식을 고르면 됩니다. |
| Q7 | 감정서랍은 무료로 이용할 수 있나요? | 감정 기록, 일기 작성, 과거 기록 조회는 무료입니다. 가입하면 카드 등록 없이 Plus 기능을 1개월 동안 체험할 수 있고, 체험이 끝나도 자동으로 결제되지 않습니다. |
| Q8 | 감정서랍에 작성한 일기는 다른 사람이 볼 수 있나요? | 기록은 내 계정으로 로그인해야만 볼 수 있고, 다른 사용자에게 공개하거나 공유하는 기능은 없습니다. 이메일 알림에는 기록 내용이나 감정 이름을 담지 않으며, 언제든 기록을 내려받거나 계정과 함께 모두 삭제할 수 있습니다. |

### F2. 4단계 감정 기록 (체험 `/try`, 회원 `/drawer/new`)

체험과 회원 작성은 **같은 화면 구성**을 쓰고 저장 방식만 다르다.

| ID | 요구사항 |
|---|---|
| F2-1 | 흐름: 시작(감정 하나 고르기) → 1 상황 → 2 생각 → 3 감정 → 4 욕구 → 마무리 **[가정]**: 기획서의 "감정 하나 선택부터 시작"과 "상황부터 차례로" 원칙을 함께 살리기 위해 시작 화면에서 고른 감정이 3단계에 미리 선택되어 있게 함 |
| F2-2 | 한 화면에 한 단계만 보인다. 상단에 진행 표시(예: 2 / 4), [이전] [다음] 버튼, 1~4단계에는 [건너뛰기] |
| F2-3 | 저장 최소 조건: 감정 1개 이상 선택 **[가정]** |
| F2-4 | 단계별 문구 (아래 표) |
| F2-5 | 감정 선택: 감정 목록(5-3)에서 최대 3개. 강도는 1~5 중 선택(선택 사항) |
| F2-6 | 욕구 선택: 욕구 목록(5-3)에서 1개(선택 사항) + 자유 입력 |
| F2-7 | 각 글 입력 칸은 최대 1,000자 **[가정]**. 남은 글자 수 표시 |
| F2-8 | 마무리 화면: 입력한 4단계를 요약해 보여주고 "오늘의 마음을 서랍에 담았어요. 천천히 돌아봐도 괜찮아요." 문구 |

| 비밀번호 확인 불일치 | 가입 막음 | 비밀번호가 서로 달라요. |
| 필수 동의 미체크 | 가입 막음 | 이용약관과 개인정보 처리에 동의해 주세요. |
| 로그인 실패 (이메일 없음/비밀번호 틀림) | 같은 문구 | 이메일 또는 비밀번호가 올바르지 않아요. |
| 감정 0개로 저장 시도 | 저장 막고 3단계로 이동 | 감정을 하나 이상 골라 주세요. |
| 감정 4개 이상 선택 | 4번째 선택 막음 | 감정은 3개까지 고를 수 있어요. |
| 글자 수 1,000자 초과 | 입력 막음, 서버에서도 거부 | 1,000자까지 적을 수 있어요. |
| 작성 중 로그인 만료 | 저장 요청 실패 → 로그인 후 브라우저 임시 보관본 복구 | 다시 로그인하면 쓰던 기록을 이어서 담을 수 있어요. |
| 저장 버튼 연속 클릭 | 첫 요청 처리 중 버튼 비활성화, 중복 저장 없음 | — |
| 다른 사람 기록 / 없는 기록 주소 | 404 | 기록을 찾을 수 없어요. |
| 체험 종료 후 Plus 주소 직접 접근 | 잠금 화면 | Plus는 출시를 준비하고 있어요. |
| 계정 삭제 확인 문구 불일치 | 버튼 비활성 유지 | '삭제'를 정확히 입력해 주세요. |
| 기록 0개에서 내려받기 | 빈 CSV 대신 안내 | 아직 내려받을 기록이 없어요. |
| 브라우저 저장소 사용 불가(사생활 보호 모드 등) | 체험은 진행, 새로고침 시 내용 사라짐 | 이 브라우저에서는 임시 보관이 되지 않아요. 새로고침하면 쓴 내용이 사라질 수 있어요. |
| 서버 오류 | 오류 화면, 입력 내용은 브라우저에 유지 | 잠시 문제가 생겼어요. 쓴 내용은 그대로 있으니 잠시 후 다시 시도해 주세요. |

## 9. 완료 기준 (체크리스트)

### 랜딩
- [ ] 휴대폰 화면(360px)에서 랜딩 전체를 볼 때 가로 스크롤이 생기지 않는다.
- [ ] 히어로 제목·본문·보조 문구가 F1-2와 글자 하나까지 같다.
- [ ] FAQ 8개를 각각 눌러 열고 닫을 수 있고, 페이지 소스에 FAQPage JSON-LD 8개 질문이 있다.
- [ ] 푸터의 "지금 많이 힘들다면"을 누르면 F8-2 안내가 보인다.
- [ ] 로그인한 상태로 랜딩에 오면 보조 버튼이 "내 서랍 열기"로 보인다.

### 체험
- [ ] 로그인하지 않은 상태로 [감정 하나 골라보기] → 4단계 → 마무리 화면까지 갈 수 있다.
- [ ] 시작 화면에서 고른 감정이 3단계에 선택된 상태로 보인다.
- [ ] 체험 중 개발자 도구 네트워크 탭에 기록 내용이 서버로 전송되는 요청이 없다.
- [ ] 체험 2단계에서 새로고침해도 입력한 내용이 남아 있다.
- [ ] 체험 후 [서랍에 보관하기] → 가입 → [보관하기]를 누르면 내 서랍에 그 기록 1개가 보인다.
- [ ] [보관하지 않기]를 누르면 내 서랍이 비어 있고, 브라우저 임시 보관도 지워져 있다.

### 회원
- [ ] 비밀번호 "abcdefgh"로 가입하면 8장의 비밀번호 규칙 안내가 나오고 가입되지 않는다.
- [ ] DB의 users 테이블에 비밀번호 원문이 저장되지 않는다.
- [ ] 틀린 비밀번호와 없는 이메일로 로그인할 때 같은 문구가 나온다.
- [ ] 로그아웃 후 `/drawer`를 주소창에 입력하면 로그인 화면으로 이동한다.
- [ ] 가입 직후 내 서랍 상단에 "Plus 체험 중 (D-30)"이 보인다.

### 기록
- [ ] 감정을 고르지 않고 저장하면 "감정을 하나 이상 골라 주세요."가 나오고 저장되지 않는다.
- [ ] 감정 4개째를 고를 수 없다.
- [ ] 저장한 기록이 내 서랍 맨 위에 보이고, 눌러서 4단계 전체를 볼 수 있다.
- [ ] 기록을 수정하면 상세 화면에 수정한 내용과 수정일이 보인다.
- [ ] 기록을 삭제하면 목록에서 사라지고 DB에서도 해당 행이 없다.
- [ ] 계정 A로 만든 기록의 주소를 계정 B로 열면 "기록을 찾을 수 없어요."가 나온다.
- [ ] 감정 필터에서 '불안'을 고르면 불안이 포함된 기록만 보인다.

### 회고·Plus
- [ ] 기록 2개일 때 회고 화면에 "(지금 2개)" 안내가 나온다.
- [ ] 기록 3개 이상일 때 최근 30일 감정별 횟수와 요약 문장이 보인다.
- [ ] 회고 화면 하단에 F5-6 문구가 항상 보인다.
- [ ] DB에서 `plus_trial_ends_at`을 어제로 바꾸면 기간 선택·함께 기록된 마음·검색이 잠기고 "Plus는 출시를 준비하고 있어요."가 보인다.
- [ ] 체험 종료 계정으로 Plus 기능 주소를 직접 입력해도 잠금 화면이 나온다.

### 설정·개인정보
- [ ] 이메일 수신 동의를 끄면 DB의 `marketing_consent`가 0이 되고 시각이 기록된다.
- [ ] [내 기록 내려받기]로 받은 CSV를 엑셀에서 열면 한글이 깨지지 않고 기록 수와 줄 수가 같다.
- [ ] 계정 삭제 후 같은 이메일로 로그인할 수 없고, DB에 그 사용자의 entries·entry_emotions 행이 없다.

### 측정
- [ ] GA4 측정 ID를 넣으면 실시간 보고서에서 `try_start`, `try_complete`, `sign_up`, `entry_create`가 확인된다.
- [ ] GA4로 보내는 이벤트 매개변수에 기록 내용·감정 이름·이메일이 없다.
